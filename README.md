## 项目简介

Mio的日记本是一个现代化的全栈个人日记应用，采用前后端分离架构。支持富文本编辑、图片上传、情绪追踪、分类管理、评论互动等功能。

**最新版本 v2.1.0** 带来了 AI 智能审核系统、评论管理功能、分类管理系统、写作统计分析等重大更新。

## 快速开始

### 环境要求

| 组件 | 版本 | 说明 |
|------|------|------|
| Node.js | 18+ | 必须 |
| npm | 9+ | 必须 |
| Git | 2+ | 必须 |
| Redis | 6+ | 必须（验证码存储、登录限流） |

### 一键安装

```bash
# 克隆项目
git clone https://github.com/zlyawa/mio-diary.git
cd mio-diary

# 安装并启动
./mio.sh install
./mio.sh start-log
```

访问 `http://localhost:5173` 即可使用。

### 首次登录

安装完成后，第一个注册的用户会自动成为**管理员**。

### 管理命令

| 命令 | 说明 |
|------|------|
| `./mio.sh install` | 安装依赖 |
| `./mio.sh start` | 启动服务 |
| `./mio.sh start-log` | 启动并显示日志 |
| `./mio.sh stop` | 停止服务 |
| `./mio.sh restart` | 重启服务 |
| `./mio.sh status` | 查看状态 |
| `./mio.sh log` | 查看实时日志 |
| `./mio.sh log-backend` | 查看后端日志 |
| `./mio.sh build` | 构建生产版本 |

### 🤖 AI 智能审核 (v2.1.0 新增)

| 功能 | 说明 |
|------|------|
| 内容审核 | 自动识别违规内容（暴力、色情、政治等） |
| 图片审核 | 支持审核评论中的图片内容 |
| 阈值配置 | 可配置低/中/高三档审核阈值 |
| 自动降级 | API故障时自动转人工审核 |
| 测试接口 | 系统设置中可直接测试AI审核效果 |

**审核流程**：
```
评论提交 → 评论审核开关开启？
    ↓ 是
AI审核启用？
    ↓ 是              ↓ 否
AI审核内容      直接进入管理员审核
    ↓
├─ 通过 → 直接发布
├─ 疑似 → 管理员审核
└─ 拒绝 → 拒绝提交
```

## 常见问题

**Q: 依赖安装失败？**
```bash
rm -rf node_modules package-lock.json
npm install --legacy-peer-deps
```

**Q: 端口被占用？**
```bash
lsof -i :3001  # 查找后端端口
lsof -i :5173  # 查找前端端口
kill -9 <PID>
```

**Q: 重置数据库？**
```bash
cd backend && npx prisma migrate reset
```

**Q: 忘记管理员密码？**
```bash
cd backend && npx prisma studio
# 在 User 表中找到用户，将 role 改为 admin
```

**Q: AI审核不生效？**
1. 检查系统设置中是否启用了评论审核
2. 检查是否配置了智谱AI API Key
3. 使用系统设置中的测试接口验证配置

**Q: Redis连接失败？**
```bash
# 检查Redis状态
redis-cli ping

# 启动Redis
./mio.sh restart
```
