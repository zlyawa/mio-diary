# 更新日志

## [2.1.0] - 2026-02-17

### 新增功能

**AI 智能审核系统**
- 集成智谱 AI API 进行评论内容审核
- 支持图片内容审核（多模态）
- 可配置审核阈值（低/中/高风险）
- 自动降级机制（API 故障时转人工审核）
- 请求队列和限流控制
- 测试接口：系统设置中可直接测试 AI 审核

**评论管理系统**
- 管理员评论列表页面（查看所有评论）
- 管理员评论审核页面（审核待审核评论）
- 用户"我的评论"页面（查看自己的评论）
- 评论图片显示支持（新旧格式兼容）
- 评论批量审核/删除

**审核流程优化**
- 评论审核开关逻辑修复
- AI 审核 + 管理员审核可组合使用
- 审核结果邮件通知
- 审核结果站内通知

**分类管理系统**
- 多级分类支持，树形结构展示
- 分类颜色标识，视觉区分
- 分类下日记数量统计
- 点击分类直接查看相关日记
- 管理员可创建、编辑、删除分类

**写作统计分析**
- 写作热力图：可视化展示写作频率
- 心情趋势图：分析心情变化规律
- 词云展示：提取日记高频词汇
- 写作习惯分析：统计写作时间段分布
- 支持切换年度/月度视图

**收藏夹功能**
- 日记收藏功能
- 收藏夹分类管理
- 快速查看收藏列表
- 取消收藏支持

**个人主页增强**
- 用户背景图展示
- 最近日记预览
- 统计数据展示（日记数、获赞数）
- 访客可查看公开日记

### 优化改进

**默认配置优化**
- `allowRegister` 默认改为 true（允许新用户注册）
- `enableComment` 默认改为 true（开启评论功能）
- 确保新安装部署后可正常使用

**邮件系统修复**
- 修复邮件模板变量未替换问题
- 支持两种邮件发送调用方式
- 审核通知邮件包含用户名

**用户体验**
- 未登录状态优化：不再频繁弹窗提示错误
- 认证错误静默处理，提升用户体验
- 页面加载状态优化
- 收藏入口移至用户下拉菜单
- 评论菜单独立分组

**系统监控**
- 修复系统监控状态显示问题
- 添加完整的状态映射
- 添加系统资源监控（磁盘空间、内存使用）
- 添加自动刷新功能

**后端优化**
- SQLite 兼容性修复
- Prisma 模型优化
- 错误处理机制完善
- 评论图片存储优化（独立 images 字段）

### Bug 修复

- 修复评论提交数据格式错误
- 修复评论列表图片不显示问题
- 修复评论审核开关不生效问题
- 修复邮件模板变量 {{username}} 未替换
- 修复日记提交数据格式错误

**数据库**
